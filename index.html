导入 Clash Verge Rev 步骤：
  1. 点击上方 “下载 dual_fusion.yaml” 按钮保存到电脑。
  2. 打开 Clash Verge Rev -> 点击左侧 【订阅】(Profiles) 菜单。
  3. 点击右上角 【新建】 -> 类型选择 Local (本地配置)。
  4. 将下载好的 dual_fusion.yaml 拖拽到窗口中，或点击导入并选择该文件。
  5. 右键该配置卡片 -> 点击 【使用】(Select) 即可完成热加载！
